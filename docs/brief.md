# Brief: Kyra Elife

## Cliente

- Nombre: Kyra Elife (Instagram @kyra.elife)
- Rubro: detalles personalizados hechos a mano
- Ubicación: Providencia, Santiago
- Slogan: "Detalles únicos hechos con amor"

## Objetivo del sitio

Mostrar los productos y que el visitante cotice fácil (hoy todo es por DM de Instagram).

## Público

Personas que buscan un regalo o detalle personalizado para una celebración.

## Productos

- Bordados (toallas con nombre o inicial)
- Toppers para tortas
- Chapitas
- Llaveros
- Accesorios y regalos

## Ocasiones

Cumpleaños, aniversarios, baby shower, graduaciones, bodas, bautizos,
inauguración de casa, celebraciones de mascotas.

## Secciones del sitio (una sola página)

1. Header: logo + menú
2. Portada (hero): slogan + botón "Cotiza tu diseño"
3. Productos: tarjetas con foto y descripción
4. Ocasiones
5. Galería de trabajos
6. Cómo cotizar: 3 pasos
7. Contacto: Instagram, WhatsApp, ubicación
8. Footer

## Guía de estilo

- Estilo: tierno, delicado, femenino (corazones, huellitas, destellos)
- Colores:
  - Rosa pastel: #F4C6CF
  - Rosa acento: #D9809A
  - Crema (fondo): #FFF8F5
  - Texto: #2B2B2B
  - Gris suave: #8A8A8A
- Tipografías (Google Fonts):
  - Títulos: Cormorant Garamond (serif elegante, como el logo)
  - Detalles: Dancing Script (manuscrita, como "Hecho con amor")
  - Texto: Nunito (redondeada y fácil de leer)
